Found a problem or have an idea for the game? A useful report makes the next adventure better.

Report a game issue

You can submit feedback through the project’s public GitHub issue tracker. A GitHub account is required to post. Please include your browser, device, what happened, and the steps to reproduce it. Do not include private or sensitive information: issues may be publicly visible.

Open the issue tracker →

Privacy questions

Use the same tracker for general privacy questions, without sharing personal information. Local game data can be removed using “Clear saved scores” on the game page or your browser’s site-data settings. This website has no contact form and does not transmit messages itself.

Before you report

Try restarting the game and updating your browser. If scores are not retained, check whether your browser blocks local storage or is in private browsing mode.
